# Dragon HD RGBA Runtime Candidate

Date: 2026-08-07

## Scope

This checkpoint turns the existing 134-pose Dragon repair-review corpus into a
deterministic package candidate for the existing Python Character Director. It
does not approve candidate artwork, admit Dragon to the production character
registry, or claim that the deferred full Dragon corpus is complete.

The package is generated by extending
`tools/build_hd_rgba_character_candidate.py`, the same builder used for the
audited Robin and Speech HD RGBA candidates. It does not introduce a parallel
renderer or runtime.
