## Review cadence

Each gate uses four reviews: design (story/geography), art (style/scale), technical (schema/runtime), and continuity/clearance. Rejected concepts stay versioned with the reason; they never silently become masters.

## Priority recommendation

After G0–G3, produce one vertical slice: `Lantern Walk exterior → Lantern & Lark interior → Joeville Creek transition → Castle Grace great-room gathering`. It tests outdoor travel, interior dialogue, moving transition, foreground occlusion, and ensemble capacity before the library expands.
